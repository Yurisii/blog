# regex
문자열 내에서 패턴을 검색하거나 교체하기 위한 도구. 정규 표현식은 특정한 형식이나 규칙을 가진 문자열을 식별하는 데 사용됩니다. 주로 데이터 검증, 문자열 조작, 텍스트 검색 등에 활용됩니다.

1. **리터럴 문자**: 단순히 일치할 문자열을 명시합니다.
    
    - 예: `abc`는 문자열 "abc"와 일치합니다.
2. **메타 문자**: 특별한 의미를 부여받은 문자.
    
    - `.` : 임의의 단일 문자와 일치합니다.
    - `*` : 앞의 요소가 0번 이상 반복됨을 의미합니다.
3. **문자 클래스**: 대괄호 `[]` 안에 문자 집합을 지정하여, 이 중 하나와 일치.
    
    - 예: `[abc]`는 'a', 'b', 'c' 중 하나와 일치.
4. **수량자**: 반복을 지정합니다.
    
    - `?` : 0 또는 1회 반복.
    - `+` : 1회 이상 반복.
    - `{n,m}` : n회 이상, m회 이하 반복.
5. **그룹**: 소괄호 `()` 안에 묶어서 표현식 부분을 그룹화합니다.


#### 예시
```python
import re

text = "Hello World 123"
pattern = r"Hello\sWorld\s\d+"

match = re.match(pattern, text)
if match:
    print("Pattern matched!")
```

위 예시에서 `\s`는 공백을 의미하고, `\d+`는 하나 이상의 숫자와 일치합니다. "Hello World"와 숫자가 있는 문장과 매칭합니다.

정규 표현식은 강력한 도구이지만 사용하기 복잡할 수 있습니다. 꾸준한 연습과 다양한 예제를 통해 익숙해질 수 있습니다.
