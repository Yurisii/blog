인터프리터는 소스 코드를 **한 줄씩 읽고, 해석(실행)하는 프로그램**입니다. 전체 코드를 한꺼번에 기계어로 번역하는 컴파일러와는 다르게, 실행 시점에 **실시간으로 동작**합니다.

### 방식
1. **한 줄씩 해석 및 실행**
   - 소스 코드를 읽고, **바로 해석해서 실행**합니다.
2. **중간 산출물 없음**
   - C 컴파일러처럼 `.exe` 나 `.out`같은 **실행 파일을 만들지 않습니다.**
3. **실행 속도 느림**
   - 해석하면서 실행하기 때문에, 컴파일된 프로그램보다 **일반적으로 느립니다.**
4. **디버깅이 쉬움**
   - **오류가 발생한 줄에서 바로 중단**되기 때문에, **디버깅**과 실험에 용이합니다.
5. **운영체제 독립성**
   - 인터프리터만 해당 OS에 맞게 설치되어 있으면, 코드는 그대로 사용할 수 있습니다.

#### 컴파일러 vs 인터프리터
| 항목             | 컴파일러 (C)       | 인터프리터 (Python, JavaScript 등) |
| -------------- | -------------- | ---------------------------- |
| **번역 시점**      | 실행 전           | 실행 중                         |
| **실행 속도**      | 빠름             | 느림                           |
| **에러 발견 시점**   | 전체 컴파일 후       | 실행 중 바로 발견                   |
| **생성물**        | 실행 파일 (.exe 등) | 없음                           |
| **코드 수정 후 실행** | 다시 컴파일 필요      | 바로 실행 가능                     |
