## Makefile?

`Makefile`은 여러 파일로 구성된 소프트웨어 프로젝트를 자동으로 컴파일하기 위한 규칙과 지침을 제공하는 스크립트입니다. 주로 C/C++ 등의 컴파일 언어에서 사용되며, 복잡한 프로젝트에서 수작업 없이 효과적으로 빌드를 관리할 수 있도록 도와줍니다. 

### 주요 개념

- **타겟(Target)**: 빌드할 파일이나 목표입니다. 보통 실행 파일이나 오브젝트 파일을 타겟으로 설정합니다. 
- **의존성(Dependencies)**: 타겟이 빌드되기 전에 필요한 파일들입니다. 예를 들어, C 프로그램이라면 `main.c`, `utils.h` 등이 될 수 있습니다.
- **명령어(Commands)**: 각 타겟을 빌드하기 위해 실행되어야 하는 구체적인 셸 명령어들입니다. Makefile 내에서 명령어 줄은 반드시 탭(TAB)으로 시작해야 한다는 점이 중요합니다.

이러한 구조를 통해 `make`라는 명령을 활용하면 최적화된 빌드 프로세스를 수행할 수 있습니다. 예를 들어, 변경된 부분만 다시 컴파일 함으로써 시간을 절약할 수 있습니다.


## 예제

**프로젝트 구성**
```css
project/
├── main.c
├── utils.c
├── utils.h
└── Makefile
```

**Makefile 작성**
```make
# 컴파일러와 플래그
CC = gcc
CFLAGS = -Wall -g

# 소스 파일과 오브젝트 파일 목록
SRCS = main.c utils.c
OBJS = $(SRCS:.c=.o)

# 최종 실행 파일 이름
TARGET = main

# 빌드 기본 타겟
all: $(TARGET)

# 링크 단계
$(TARGET): $(OBJS)
	$(CC) $(CFLAGS) -o $@ $^

# .c → .o 컴파일 규칙 (패턴 규칙)
%.o: %.c
	$(CC) $(CFLAGS) -c $< -o $@

# clean: 중간 파일 제거
clean:
	rm -f $(OBJS) $(TARGET)

```


## 사용법

| 명령어           | 설명                                                |
| --------------- | --------------------------------------------------- |
| `make`          | 기본 target(`all`) 실행                             |
| `make [타겟]`   | 특정 타겟 빌드 (예: `make main`)                    |
| `make clean`    | 빌드된 파일 삭제                                    |
| `make -n`       | 실제 실행될 명령어만 출력 (dry-run)                 |
| 패턴 규칙       | `%.o: %.cpp` 같은 형식으로, 유사한 패턴의 파일 처리  |
| 자동 변수       | `$@`: 현재 타겟, `$^`: 모든 의존 파일, `$<`: 첫 번째 의존 파일  |
| 변수 확장       | `$(SRCS:.cpp=.o)`로 확장자 변환하여 목록 생성       |
| 기본 타겟       | `all`로 프로젝트 전체 빌드 가능                      |

## 주의사항
- 명령어 줄은 반드시 TAB으로 시작해야 함(`space` 아님)
- `dependencies`에 `.h`파일도 꼭 넣어야 의존성 제대로 추적됨
- `make`는 변경된 파일만 다시 컴파일함(이게 핵심 기능)
