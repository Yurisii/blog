# Register Transfer Level
RTL은 하드웨어의 **동작(Behavior)을 중심**으로 **Register 간 데이터 전송과 연산**을 통해 칩의 기능을 추상적으로 기술한 설계 코드.

> **"무엇을 할 것인가(What)"를 기술하는 설계 언어.**

RTL은 칩 설계의 초기, 즉 Front-end 설계 단계에서 사용된다. 설계자는 칩이 수행해야 할 **기능(덧셈, 데이터 처리, 조건 판단 등)**을 [[Verilog]]나 [[VHDL]] 같은 HDL을 사용하여 코드로 작성한다. 이 코드는 실제 하드웨어 부품을 명시하는 대신, 프로그래밍 언어처럼 논리적인 흐름과 동작에 집중한다.

- **높은 가독성:**
  사람이 읽고 쉬워 복잡한 기능도 효율적으로 설계하고 수정할 수 있다.
- **기술 독립성(Technology-Independent):**
  특정 반도체 파운드리의 공정 기술에 얽매이지 않는다. 어떤 Cell Library를 사용할지 결정하기 전 단계이므로, 설계의 재사용성이 높다.
- **빠른 기능 검증:**
  시뮬레이션을 통해 하드웨어의 동작을 빠르게 검증하고 논리적 오류를 초기에 발견할 수 있다.

```verilog
// 8bit Adder Module
module Adder_RTL (
    input [7:0] a,
    input [7:0] b,
    output [7:0] sum
);

    // 'a + b를 sum으로 출력한다'는 동작을 기술
    assign sum = a + b;

endmodule
```

위 코드에서는 `+`연산자를 사용하여 덧셈이라는 **'기능'**을 표현했을 뿐, 이 덧셈을 어떤 종류의 AND, OR 게이트로 구현할지 언급하지 않았다.
