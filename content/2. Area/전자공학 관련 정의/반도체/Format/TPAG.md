# Test Pattern Automatic Generation
**웨이퍼 테스트 (wafer sort)** 단계에서 사용되는 **[[Test Pattern#Test Pattern|테스트 패턴]] 자동 생성용 파일 포맷**이다. 이 포맷은 특정 좌표(X, Y)에 있는 **칩의 패드**들에 대해, 각 패드가 어떤 **핀(또는 Net I/O 이름)에 해당**하며 그 핀에 어떤 **테스트 패턴**을 적용해야 하는지를 정의한다. 쉽게 말해 **Probe 카드로 짝는  각 패드에 어떤 테스트 신호를 넣고 어떤 응답을 볼지**를 미리 맵핑해놓은 **테스트 플랜** 파일이라고 볼 수 있다. TPAG 파일을 활용하면 테스트 엔지니어가 일일이 패드와 패턴의 대응을 수작업으로 설정하지 않아도, 툴이 자동으로 해당 정보를 읽어 **테스트 벡터**를 생성하거나 패턴을 할당하게 된다.

- **생성 시점 및 flow:**
  TPAG 파일은 보통 칩 설계 완료 후 웨이퍼 생산이 이루어지고, 웨이퍼 프로브 테스트를 준비하는 단계에서 만들어진다. 테스트 개발 엔지니어는 Pad Layout Data를 설계 부서로 받아, 각 신호 핀에 대한 **테스트 패턴 요구사항을 반영**한다. 이 과정에서 TPAG 포맷 파일이 생성되고 **ATE(Automatic Test Equipment)** 테스트 프로그램에 **import** 되거나 패턴 생성 SW에서 읽혀져 실제 ATE가 **실행할 [[Test Pattern#Test Vector|테스트 벡터]] 파일들을 자동으로 생성**하는데 사용된다. 따라서 TPAG 파일은 웨이퍼 테스트 프로그램 개발 단계에서 활용되며, 웨이퍼 프로빙을 실시하기 전에 **테스트 패턴 로딩/매핑 용도**로 준비된다.
- **사용 목적:**
  웨이퍼 테스트의 **자동화와 정확도 향상**이다. 구체적으로 웨이퍼 상의 칩 패드와 해당 패드에 인가할 테스트 패턴을 **미리 매핑**함으로써, ATE 상에서 핀 설정과 벡터 적용을 일관되게 설정할 수 있다. 대상 툴은 주로 반도체 테스터 장비 소프트웨어나 패턴 생성 툴이다. TPAG는 테스트 엔지니어가 ATE에 **"어느 패드 -> 어떤 신호 이름 -> 어떤 패턴 사용"**을 알려주는 매개체 역할을 하며, 이를 통해 사람의 실수를 줄이고 테스트 프로그램을 신속히 구성하도록 도와준다.
- **포함 정보 항목:**
  TPAG는 일반적으로 칩의 패드 위치, 핀/신호 이름, 적용할 테스트 패턴 specifier 등의 컬럼으로 구성된다. 정확한 형식은 회사나 장비에 따라 다를 수 있다.
  - _**Pad X/Y 좌표**_:
    웨이퍼 상에서 각 패드가 위치한 좌표 값. 보통 해당 다이의 좌표계에서 **패드 중심의 X, Y 위치**로 주어진다. 이 좌표는 **프로브 카드가 정확히 해당 패드를 찌를 수 있도록 사용**되며, 칩 내 패드 식별에도 활용된다.
  - _**Pin (Net) Name**_:
    해당 **패드에 연결된 신호 이름 또는 핀 이름**이다. 이는 디자인 상 논리 핀과 물리 패드를 연결짓는 정보로, **테스트 패턴을 어떤 신호에 적용할 지를 결정**하는 키다.
  - _**Test Pattern ID/Name**_:
    각 핀에 대해 적용할 **테스트 패턴의 이름 또는 ID를 명시**한다. 예를 들어 디지털 신호라면 특정 기능 테스트 패턴 이름을, 아날로그 핀이면 DC 측정 패턴이나 특정 파형 패턴 이름을 지정할 수 있다.이로써 해당 **패드에 프로버가 닿았을 때 ATE가 어떤 테스트 벡터를 실행할 지 자동으로 정해진다.** 경우에 따라 테스트 모드 설정, 파라메트릭 한계 등의 부가 정보가 포함될 수 있지만, 핵심은 **핀 대 패턴 매핑**이다.


>[!reflection]
>칩을 만들고 나면, 바로 제품에 사용하기 전에 테스트를 해야 한다. 그 테스트는 웨이퍼 상태에서 Probe로 칩 위에 신호를 넣고 확인하는 방식이다. 이때 필요한 게 있는데.
>- 어디를 눌러야 하는가 (X, Y 좌표)
>- 그 자리가 어떤 핀인가.(IO name, Net name)
>- 거기에 어떤 테스트 패턴을 사용할 것인가
>
>**==칩 패드와 테스트 패턴을 연결해주는 웨이퍼 테스트 단계의 패턴 매핑 포맷==**
