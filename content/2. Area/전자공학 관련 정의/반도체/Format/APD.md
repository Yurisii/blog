# Allegro Package Design

- **format 개념 :**
  APD 파일은 주로 **[[Package|패키지]] 기판 설계** 단계에서 사용하는 입력 데이터 포맷이다. 칩 다이의 **범프(bump) 배열 정보**를 바탕으로 패키지 기판 위에 **볼맵(ball map)**을 정의하고, 각 범프와 패키지 볼을 **전기적으로 연결([[Auto P&R (CTS&ROUTE)#Route|routing]])** 하기 위한 정보를 담고 있다. 이 파일을 통해 패키지 설계자는 다이 I/O와 패키지 핀 간의 연결 관계를 손쉽게 가져와 설계에 반영할 수 있다.
- **생성 시점 및 flow 상 위치:**
  APD 포맷 데이터는 칩 설계 완료 후, **패키지 기판 설계를 시작할 때 생성**된다. 구체적으로, 칩의 범프 배치와 I/O 핀 구성이 확정되면 칩 설계 팀이나 I/O 플래너가 해당 정보를 export해서 APD 텍스트 파일을 만든다. 이 파일은 **패키지 기판 설계 툴에서 import** 되어, 기판 상의 **다이의 패드 패턴과 볼 위치를 자동으로 배치하는 데 사용**된다. 즉 **칩-패키지 [[Co-design|co-design]] 초기에, 다이와 패키지 간 배선 연결 계획을 수립하는 단계에서 활용**된다.
- **포함 정보:**
  패키지 기판 상 다이 I/O 연결에 관한 다양한 정보를 열(column) 형식으로 담고 있다. 회사나 툴에 따라 세부 형식은 다를 수 있지만, 일반적으로 다음과 같은 필드를 포함한다.
  (정보들은 **다이의 각 범프가 패키지 기판의 어떤 볼(pin)과 어떻게 연결되는지를 완전히 기술**한다. 한 행은 다이의 특정 범프가 기판의 어떤 좌표에 어떤 패드스택 형태로 배치되고, 패키지에서는 어떤 핀 명과 네트로 불리며, 다이 내부에서는 어떤 신호로 연결되는 지를 나타낸다.)

| **필드명**            | **설명**                                                         |
| ------------------ | -------------------------------------------------------------- |
| Pin_number         | 핀 번호 또는 패드 일련번호 (범프 식별자)                                       |
| Padstack           | 사용하는 패드스택 이름 (기판 패드 형태)                                        |
| X/Y 좌표             | 기판 상 패드의 X, Y 위치 좌표 (단위: 보통 μm)                                |
| Rotation (회전)      | 패드의 회전 각도 (패드 모양이 비대칭일 때 사용)                                   |
| Pad_use            | 패드 용도 (예: **전원**, **접지**, **신호** 등)                            |
| Net_name (Package) | 패키지 측에서의 네트 이름                                                 |
| Net_name (DIE)     | 다이 내부의 네트 이름 (범프에 대응되는 신호명)                                    |
| Cell_name          | 해당 패드가 속한 셀 이름 (예: I/O 셀 또는 범프 셀 이름)                           |
| Pad_type           | 패드 유형 (예: 범프 타입, 볼 타입 등)                                       |
| Staggered_type     | 패드 배열 형태 (예: **스타거(staggered)** 여부 등)                          |
| RefDes             | 참조 디자이네이터(Reference Designator), 보통 다이 또는 패키지 부품 식별자 (예: `U1`) |
| Package_pin        | 패키지 핀 명칭 (예: BGA의 볼 좌표명 `A1`, `B2` 등)                          |


>[!reflection]
>Die 안에는 수천 개의 I/O 핀이 존재하고, 그걸 외부랑 연결하려면 substrate가 필요하다. 이 기판 위에 작은 금속 접점들(bump, ball 등)이 있고, 이걸 통해 신호나 전원이 연결된다. 그러려면 아래와 같은 정보가 필요하다.
> - 칩 위에 **어디에 어떤 Bump**가 있는지
> - 기판 위의 **Ball은 어떻게 배치**할 지
> - 그걸 **어떤 선(Routing)으로 연결**할지
> 
> **==APD 파일은 칩의 I/O 범프 맵과 패키지 볼맵을 연결해주는 설계 단계의 데이터 교환 포맷==**
