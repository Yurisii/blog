[[Timing Arc]]의 한 속성으로, 특정 셀의 입력 핀에서 발생하는 **Signal Trasition**이 출력 핀에 어떻게 영향을 미치는지를 나타내는 논리적 관계를 나타낸다. [[STA(Static Timing Analysis)|STA]]에서 delay를 정확하게 계산하는 데 필수적이다.

크게 세 가지 유형으로 나뉜다.

---

# Positive Unate : 같은 방향으로의 변화
**Positive Unate**는 입력 신호의 변화 방향과 출력 신호의 변화 방향이 **동일하게** 나타나는 관계를 의미한다.
- 입력 신호가 **Rising**하면, 출력 신호도 **Rising**한다.
- 입력 신호가 **Falling**하면, 출력 신호도 **Falling**한다.

이 관계는 신호의 논리적 상태를 **그대로 전달**하거나 **특정 조건에서만 전달**하는 게이트에서 나타난다.(BUFFER, AND, OR 게이트)

# Negative Unate : 반대 방향으로의 변화
**Negative Unate**는 입력 신호의 변화 방향과 출력 신호의 변화 방향이 **반대로** 나타나는 관계를 말한다.
- 입력 신호가 **Rising**하면, 출력 신호는 **Falling**한다.
- 입력 신호가 **Falling**하면, 입력 신호는 **Rising**한다.
이러한 특성은 주로 신호를 **반전시키는 기능**을 가진 게이트에서 발견된다. (Inverter, NAND, NOR 게이트)

# Non-Unate : 예측할 수 없는 변화
**Non-Unate**는 하나의 입력 신호와 변화 방향만으로는 출력 신호의 **변화를 단정할 수 없는** 복합적인 관계를 의미한다. 출력의 변화는 해당 입력뿐만 아니라 다른 입력 핀의 현재 상태에 따라 결정된다. (XOR, XNOR 게이트)
