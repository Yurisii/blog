# Test Vector
칩을 테스트할 때 칩에 적용할 입력값과 기대 출력값의 조합을 의미한다.
즉 ==입력값 + 기대 출력== 한 쌍이 Test Vector다.

>[!reflection]
>칩은 내부에 수천 개의 Logic Gate와 수백 개의 입출력 핀을 갖고 있다.
>이게 제대로 동작하는 지 확인하려면, 정해진 입력을 주고 올바른 출력을 확인해야 한다.
>이걸 자동화된 장비가 하려면 입력과 출력 조건을 미리 명시한 벡터 파일이 필요하다.
>-> 이게 **Test Vector**.

# Test Pattern
칩의 논리 회로나 아날로그 회로에 대해 **Test Vector**를 적용하는 것을 말한다. 
**"어떤 입력을 주고 어떤 출력을 기대하느냐"**에 대한 입출력 시퀀스 집합이다.

### 디지털 회로:

- 특정 핀에 `101010` 같은 **입력값 시퀀스**를 주고,
    
- 다른 핀에서 `110011` 같은 **기대 출력값**을 받는 식.
    
- 이때 이 입력 시퀀스와 출력 확인 조건 전체를 "테스트 패턴"이라고 한다.
    

> 예: `IN_A=1, IN_B=0 → OUT=1`  
> 이걸 ATE가 순차적으로 넣고 결과를 확인함.

### 아날로그 회로:

- 예를 들어 전압을 0.5V부터 1.8V까지 가변적으로 주고,
    
- 출력에서 증폭, 필터링, 변조 등 동작이 사양 내에서 되는지를 확인.
    
- 이런 아날로그 시나리오도 하나의 "테스트 패턴"으로 봄.
