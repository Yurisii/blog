## Package
패키지의 목적 : 반도체 칩/소자 보호

1차 레벨 패키지 : 칩을 단품화
2차 레벨 패키지 : 단품을 모듈 또는 카드에 실장
3차 레벨 패키지: 단품과 모듈이 실장된 카드를 시스템 보드에 장착

### Package의 역할
물리적 / 전기적으로 칩을 시스템에 연결
- 전기적 : 칩에 전원 공급, 신호 입/출력
- 기계적: 칩이 사용되는 공간 시스템에 잘 부착되도록 연결, 칩/소자에서 발생하는 열 발산

고속 전기 신호전달 -> 반도체 제품 속도 패키지의 영향을 받음 -> 플립 칩, TSV

### Package 분류
- **[[RDL|RDL(Re-Distribution Layer)]]:**
  칩 위에 외부와 전기적으로 연결되는 패드를 웨이퍼 레벨 공정을 통해서 재배열해주는 패키지
  (RDL은 Fan-out 및 2.5D/3D 패키지에 사용된다.)
- **Flip Chip:**
  Solder Bump를 웨이퍼에 형성시켜 패키지 공정을 진행하는 패키지
- **WLCSP(Wafer Level Chip Scale Package):**
  Substrate 등의 매개체없이 웨이퍼 위에 배선과 Solder Ball을 형성시켜 완성하는 패키지
- **TSV Package:**
  TSV를 통해서 적층된 칩의 내부 연결을 해주는 TSV 패키지.


### Package 종류
1. Package Stack
2. Chip Stack with Wire Bonding
3. Chip Stack with TSV
