# DDI(Display Driver IC)

**DDI(Display Driver IC)는 디스플레이 패널의 픽셀을 직접 구동하여 이미지를 형성하는 핵심 반도체 소자**다. [[TCON|T-CON]]에서 전달된 디지털 영상 데이터를 **픽셀이 요구하는 아날로그 구동 신호(전압 또는 전류)로 변환**하는 역할을 수행한다. T-CON이 시스템의 중앙 제어 유닛이라면, DDI는 **패널 레벨의 직접 제어 유닛**이라 할 수 있다.

DDI는 각 RGB 서브픽셀을 언제, 얼마나 밝게 켜야 하는지를 제어하는데, 이는 각 픽셀에 연결된 TFT(박막 트랜지스터)를 제어하는 방식으로 이루어진다. 해당 트랜지스터를 통해 DDI는 **Gate 신호의 타이밍**과 **색상 데이터**를 전달한다.

### 주요 기능

- **픽셀 선택 및 구동(Addressing & Activation)**:
		- 업데이트할 특정 pixel을 선택한다.
    
- **계조/색상 구현([[Gray Scale]] & Color Generation)**:
	    - 각 subpixel에 다양한 전압/전류 레벨을 공급해서 광범위의 색상과 음영을 만든다. 
	    (예를 들어, 8비트 RGB는 각각 256 단계의 Gray Scale 표현이 가능해서 총 256 x 256으로 약 1670만 가지의 색상을 표현할 수 있다.)
- **디지털 → 아날로그 신호 변환(DAC)**:
	    - 디지털 데이터 신호를 패널 기술에 적합한 아날로그 구동 신호로 변환한다.

이러한 기능은 디스플레이의 색정확도, 밝기 균일성, 응답 속도 등에 직접적으로 영향을 준다.

### 성능 요구 사항

해상도 증가(FHD → 4K, 8K), 주사율 증가(60Hz → 120Hz, 240Hz), 색 심도 증가(8bit → 10bit) 등의 트렌드는 DDI에 더 많은 데이터 처리량과 정밀도, 저전력 특성을 요구한다. 이를 위해 DDI는 **더 많은 채널 수, 빠른 내부 클럭, 전력 효율이 높은 아키텍처**를 필요로 한다.

또한, **COF(Chip On Film)** 같은 실장 기술을 통해 플렉서블 디스플레이와 같은 새로운 폼팩터 대응도 이뤄지고 있다.

### 내부 아키텍처

DDI는 일반적으로 다음과 같이 구성된다:

#### 소스 드라이버(Source Driver IC)

- 디지털 영상 데이터를 수신하여 **데이터 라인(열 방향)**으로 아날로그 구동 신호 출력
    
- 구성: 시프트 레지스터, 래치, DAC, 출력 버퍼 등
    

#### 게이트 드라이버(Gate Driver IC)

- **게이트 라인(행 방향)**에 전압 펄스를 인가해 해당 행의 TFT를 활성화
    
- 구성: 시프트 레지스터, 레벨 시프터, 출력 버퍼 등
    
- 최신 패널(LTPS, Oxide 등)에서는 GIP(Gate-in-Panel) 구조 사용
    

#### 제어 로직(Control Logic)

- T-CON과의 인터페이스, 타이밍 제어, 전력 시퀀스 제어 등 전체 동작 조율
    

#### 동작 흐름

1. T-CON으로부터 데이터 수신
    
2. 게이트 드라이버가 행 선택
    
3. 소스 드라이버가 아날로그 신호 출력
    
4. 선택된 행의 픽셀에 전압 인가 → 이미지 형성
    
5. 반복하여 전체 프레임 구현

### DDI RTL 설계 관점

RTL 설계자는 DDI를 다음과 같은 구성 블록으로 분해하여 설계한다:

- **Input Interface Block**: MIPI DSI, LVDS 등으로부터 수신한 직렬 신호를 병렬화
    
- **Timing FSM**: VSYNC, HSYNC, Pixel Clock 기반 스캔 타이밍 제어
    
- **Output Controller**: 소스/게이트 드라이버 제어 신호 생성
    
- **Power FSM**: VCOM, VGH, VGL 등 전압 시퀀스 및 안전한 ramp-up/down 관리
    
- **부가 블록**: 컬러 보정, 감마 보정, OSD 등 기능 통합
    

고속 데이터 경로 처리, 저전력 구동, 정밀한 PWM 제어, FSM 구조 설계 등은 설계 품질의 핵심 요소이다.

### LCD vs OLED에서의 DDI

|항목|LCD DDI|OLED DDI|
|---|---|---|
|구동 방식|컬럼 전압 제어|전류 또는 전압 제어 (TFT 통해)|
|주요 과제|전압 정밀도|불균일성, 픽셀 열화 보정|
|보상 기능|거의 없음|필요 (Mura 보정, Aging 보정 등)|

AMOLED의 경우 DDI는 픽셀 단위로 보정된 신호를 출력하기 위해 **온칩 메모리, 정밀 제어 FSM, 전류 보상 알고리즘** 등을 포함한다. MicroLED 등 차세대 디스플레이로 갈수록, DDI는 단순 구동기에서 **복합 센서 및 보상 제어 SoC**로 진화하고 있다.
