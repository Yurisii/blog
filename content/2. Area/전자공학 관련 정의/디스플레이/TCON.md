# T-CON(Timing Controller)

**T-CON (Timing Controller)**은 디스플레이 패널 시스템 내에서 GPU/AP로부터 받은 고수준의 비디오 데이터를 디스플레이에 적합한 저수준의 타이밍 및 제어 신호로 변환하는 **중앙 제어 유닛**이다. 보통 패널 모듈에 포함되어 있으며, **디스플레이의 "두뇌" 또는 "관제탑"**에 비유된다.

**T-CON**은 **입력 영상 데이터를 수신하고, 디스플레이 타이밍을 생성하고, [[DDI]]로 데이터를 분배하며**, 다양한 영상 보정 및 향상 기능까지 수행한다. 다음은 주요 기능이다:

---

### T-CON의 주요 기능

#### 1. 입력 수신 및 버퍼링

- [[Display Input Interface#LVDS(Low Voltage Differential Signaling)|LVDS]], [[Display Input Interface#eDP(embedded DisplayPort)|eDP]], [[Display Input Interface#DSI(Display Serial Interface)|MIPI DSI]] 등의 인터페이스를 통해 GPU/AP에서 전송된 RGB 또는 압축된 비디오 신호 수신
    
- 수신된 영상은 내부 버퍼에 저장되어 처리 준비
    

#### 2. 데이터 재구성 및 처리

- 압축 해제, 픽셀 데이터 재구성, DDI 레이아웃에 맞는 정렬 수행
    
- 프레임 리플로우, 스케일링, 서브픽셀 정렬 등 지원
    

#### 3. 화질 보정

- 감마 보정, 컬러 매핑, 밝기 조절 등을 통해 화질 개선
    

#### 4. 타이밍 신호 생성

- [[Synchronization Signal#HSYNC|HSYNC]]/[[Synchronization Signal#VSYNC|VSYNC]], 클럭, 제어 신호 등 정밀한 타이밍 생성
    
- 각 픽셀이 정확한 순서와 속도로 구동되도록 보장
    

#### 5. DDI 분배 및 제어

- 다수의 DDI로 데이터 분산, 동기화된 타이밍 제어
    

#### 6. 고급 기능

- HDR 처리, 로컬 디밍, 주사율 조절(VRR), 터치 통합, PSR(Power Save) 등 지원
    

---

### 고급 기능 요약

| 기능                  | 설명                    | 효과              |
| ------------------- | --------------------- | --------------- |
| HDR 처리              | 밝은 영역과 어두운 영역을 동시에 보존 | 명암비 향상, 디테일 유지  |
| 로컬 디밍               | LCD 백라이트를 영역별 제어      | 깊은 검정 표현 가능     |
| Adaptive Sync (VRR) | GPU 프레임과 동기화된 주사율 제어  | 게이밍 화면 끊김/잘림 방지 |
| PSR / PSR2          | 정지 프레임을 내부 저장, GPU 대기 | 배터리 절약, 발열 감소   |
| 색 공간 변환             | BT.2020 ↔ DCI-P3 등 변환 | 다양한 콘텐츠 호환성 확보  |
| 고속 출력 인터페이스         | mini-LVDS, USI-T 등    | 고해상도/고주사율 지원    |
| 이미지 향상 IP           | Line-OD, De-Mura 등    | 선명도, 노이즈 감소     |

---

### 인터페이스 구성

- **입력**: eDP, MIPI DSI, LVDS 등
    
- **출력**: DDI용 mini-LVDS, P2P 링크 등
    

---

### 디스플레이 제품에서의 의미

T-CON은 **디스플레이의 해상도, 주사율, 화질**을 좌우하는 핵심 요소로, 최신 디스플레이는 대부분 T-CON의 성능에 따라 차별화된다. 특히 고급 제품에서는 **전용 알고리즘과 펌웨어**를 통해 기능이 극대화된다.

예:

- 삼성 USI-T, Himax 288Hz 8K TCON 등은 고속 인터페이스와 고주사율 대응이 특징
    
- 로컬 디밍, 적응형 동기화, PSR 등은 T-CON 내부에서 직접 실행됨
    

---

### 결론

T-CON은 단순한 타이밍 제어를 넘어, 디스플레이의 **시각적 품질, 전력 소비, 반응성**을 결정짓는 중요한 지능형 제어 소자다. 따라서 디스플레이 설계에서 T-CON의 기능과 성능은 최종 사용자 경험을 좌우하는 핵심 설계 요소로 간주된다.
