디스플레이 인터페이스는 GPU/AP와 디스플레이 패널 사이에서 **영상 데이터를 전달하는 고속 통신 방식**이다. 주로 [[TCON]]이 해당 인터페이스를 통해 데이터를 수신하며, 디스플레이의 해상도, 주사율, 소비 전력, 배선 복잡도에 큰 영향을 미친다.
# LVDS(Low Voltage Differential Signaling)
오래된 패널 연결 표준, 병렬 RGB 데이터를 고속 직렬로 변환해 저전력 차동 방식으로 전송

특징:
- 최대 수백 Mbps 속도
- 케이블 길이에 따라 신호 열화 가능
- 2010년대 초반까지 대부분의 노트북, 모니터 LCD에서 사용

장점:
- 구현 간단, 표준화됨

단점:
- 선 수가 많다. 고해상도에 부적합하다.

# eDP(embedded DisplayPort)
DisplayPort의 모바일/내장 버전으로, LVDS를 대체한 최신 표준

특징:
- 최대 수 Gbps 전송 속도
- MST(Multi Stream Transport) 및 PSR(Panel Self Refresh) 지원
- 노트북, 고해상도 모니터에서 광범위 사용

장점:
- 전력 효율 우수(불필요한 재전송 감소)
- 더 적은 핀 수로 고해상도 지원 가능
- 프레임 리프레시 최적화 가능 (배터리 수명 향상)****

단점:
- 회로 복잡성 증가

# DSI(Display Serial Interface)
MIPI Alliance가 정의한 모바일 디스플레이 전용 직렬 통신 인터페이스, SoC에서 디스플레이 패널로 영상 신호를 전송

특징:
-  Command Mode(T-CON 내 버퍼로 전송) / Video Mode (스트리밍 전송) 모두 지원

장점:
- 배선 수 최소화, 저전력 고속 전송

단점:
- 전송 거리 짧고, 고해상도 대형 패널에는 부적합
